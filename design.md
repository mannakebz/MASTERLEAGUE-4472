# Master League — Design

Web-only football league hub using the owner's uploaded twin-circle logo. Black, fiery orange #ff5a1f, red #e93632, and golden orange accents.

## Visual direction
Site-wide theme update: keep the existing light Liquid Glass option and add an equally legible dark navy/charcoal Liquid Glass option, including public pages, overlays and Admin. Header sun/moon toggle persists per device in localStorage; light is default when no preference is saved. Use existing self-hosted Poppins: 700 for headings/navigation/key numbers, 400–500 for body copy, tables and form fields. Preserve orange accents, logo and football pitch. No API/database changes.
Updated at owner's request: modern iOS 27 / Liquid Glass-inspired light design across all public pages and administration. Preserve the orange brand, uploaded logo, stadium image and every existing feature/data value. Native Apple system typography with system fallbacks, sentence-case headlines, clear tabular numerals and readable secondary text.
Floating frosted navigation, pill controls, translucent white surfaces, specular inner borders and gentle layered shadows over a cool pearl canvas with warm orange ambient light. Glass concentrated on navigation and controls; more opaque panels keep tables/forms legible. Large 28–36px continuous-feeling panel corners, 14px inputs, 44px touch targets. Mobile uses a frosted navigation sheet and generous gutters; no clipped data tables or overflowing controls. Reduced-motion and reduced-transparency preferences receive fallbacks.
Implementation touches only web shared components/headline copy and a scoped Liquid Glass stylesheet imported after existing styles. No API/database/authentication changes. Verify all public routes, admin sign-in view, mobile menu, notification bell and statistics filters.

## Pages and flows
Overview, Teams with detail view, Standings, Fixtures & Results, News with category filters and article view, Transfers with Leone totals, Admin login and manual editing dashboard.
All match, player, transfer and financial values begin at zero. SLE currency (Sierra Leone leones). No invented dates, articles, results or transfers. Clearly explain empty sections.
Admin has email/password and managed Google sign-in. Only MASTER_LEAGUE_ADMIN_EMAIL is authorized on the server. Leave unassigned until supplied. All updates persist in database through typed oRPC.

## Implementation
Device stability pass: retain Liquid Glass appearance while adding safe-area spacing, short-landscape menus, no-blur fallbacks and resilient grid/table sizing. Protect unsaved admin edits from background refetches, provide offline/error recovery, isolate route crashes and dismiss overlays on navigation/Escape/outside taps. Test Chromium, Firefox and WebKit engines with phone/tablet/desktop viewports; do not equate emulation with physical-device certification.
packages/web only: league and auth database tables, league read and protected edit procedures; public page components, admin forms, query hooks and shared navigation. Persist validated league state in SQLite via Drizzle. Logo and stadium photography in public/images.

## Squad and performance expansion
TOTW ratings: each selected player's avatar gets the same colored, one-decimal rating badge as Overview, using only the published weekly stats whose week matches data.totw.week. No latest-week fallback or season totals. Unplayed/missing records show “Not rated”, never invented 6.0; unpublished XI placeholders have no badge. Preserve all three formations and profile links; compact circular avatars/badges fit phone pitches. No API/database or automatic XI selection changes.
Weekly ratings (supersedes season leaderboard): owner-approved formula = clamp(6.0 + goals × 1.5 + assists × 0.9 + clean sheets × position bonus − yellow cards × 0.5, 0.0, 10.0); any red card overrides to 0.0. Only marked participants receive ratings; others have no numeric badge. One decimal. Clean-sheet bonus per sheet: DEF +1.5, MID +1.2, FWD (wingers/strikers) +1.0, GK +1.0; no division by appearances. Store weekly records independently from season totals in existing league_state JSON, backwards-compatible empty default. Admin Weekly ratings tab selects/adds a positive league week number and team, marks played and enters weekly goals/assists/cards and clean sheets for all positions with live derived preview. Existing protected league.save publishes and preserves history; league.get returns published records. No new database table or auth changes. Overview defaults to latest published week with week/team selectors, four team panels and all 15 players each. Circular existing photos, top-right colored score pills (blue 9+, green 7+, orange below 7, red below 5), understated nonparticipant state and compact weekly stat captions, retaining the light Liquid Glass brand. Empty history is honestly indicated, never inferred from season totals. Reference image informs avatar/badge composition, not a formation or dark theme. Publish changes generate a weekly-rating notification.
Player transfer values: every player gets nonnegative whole-SLE transferValue (default 0, max 1 billion). Backwards-compatible schema default preserves existing data. Editable under Admin → Players for each chosen team; grouped four-team valuation section on Transfers, same section on individual team pages, individual profile value and derived squad totals. Valuations do not affect transfer fees, team budgets or transfer spending. Changes generate transfer-centre update alerts.
Add 60 fictional editable sample player names, 15 per team. Each profile: position, number, photo, appearances, goals, assists, clean sheets, yellow/red cards, bio; G/A derived as goals plus assists. All performance stats stay zero. Sample players are not counted as officially registered until admin marks them real.
Notification expansion: header bell with device-local unread state and public recent update feed. Published news, fixture/result, transfer, squad/team stats and published TOTW changes create persisted events, no notification on unchanged saves or private TOTW drafts. Opt-in standards-based Web Push with protected unsubscribe capability, generated VAPID keys in root .env, service worker and install manifest. Public subscription API validates known push-provider URLs to prevent server-side request forgery. Yellow/red cards gain visible colored counters in squads, profiles, team totals and disciplinary leaderboard. Keep no invented initial announcements.
Stats centre has top scorers, assisters, G/A and team metrics. Team profiles show exactly 15 squad members. TOTW uses admin-selected unique 11 players in 4-3-3, 4-4-2 or 3-5-2; empty initial selection is honestly shown on pitch. Admin photo uploads for players, team crests and news use protected S3 presigning, stored object keys, fresh read URLs. Keep existing brand and responsive layout.
